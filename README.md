**About the repo**
---
This repo is the source (and public shame folder) for the exact NixOS 
configuration and flakes I run as my daily driver. It's part changelog, 
part knowledge dump, and part back-up. 

I haven't written a directory overview because this machine is a living 
organism. Modules get added, moved, and quietly deleted at 2am. An 
overview would be out of date by the time I finished writing it.

**Why NixOS?**
---
As a national finalist at CHPC SCC (Student Cluster Competition), I fell 
hard for Linux; specifically Linux for development. My mentor suggested 
I try NixOS to actually learn deployment, DevOps, and declarative systems, 
as I also have a passion for scripting.

**About the system thus far**
---
I've since fallen face-first into the Desktop Ricing rabbit hole. Right 
now the system runs Niri as the Wayland compositor. I've included my full 
configuration file both as a backup and as an honest snapshot of where 
I'm at including: mistakes and structure I clearly meant to fix later.
